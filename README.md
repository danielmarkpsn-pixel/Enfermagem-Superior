# Enfermagem Superior — V6.0

Portal acadêmico educacional em HTML/CSS/JavaScript.

## Novidades da V6

- Cadastro local de novos usuários.
- Login por e-mail e senha demonstrativos.
- Perfis de Aluno, Professor e Administrador.
- Gestão de usuários.
- Painel por perfil.
- Gestão de materiais/PDFs.
- Banco de questões.
- Criação de avaliações.
- Notas.
- Frequência.
- Calendário.
- Avisos.
- Backup e restauração JSON.
- Tema claro/escuro.
- 8 semestres e 45 componentes curriculares.
- Estrutura documentada para backend real.

## Atenção

O login atual é local e demonstrativo. Não use senhas reais neste modo. Para uso institucional/multiusuário, conecte autenticação, banco de dados e armazenamento de arquivos.

Este projeto é uma plataforma educacional e não constitui, por si só, graduação oficialmente reconhecida.
